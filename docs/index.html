GAME INTRODUCTION

게임 소개배경 설정

당신은 이 도시의 모든 시민 기록을 보관하고 처리하는 국가 기관의 신입 직원이다.
매일 들어오는 사건 파일을 열고, 검토하고, 처리하면 그만이다.
당신의 선택은 도시의 질서와 시민의 신뢰, 그리고 이 시스템 자체를 바꿔나간다.

STORY DATA FORMAT

스토리 데이터 형식StoryNode JSON 구조

기본 구조 예시
{
  "id": "case_1042",
  "sfx": "Assets/audio/node_paper.wav",
  "bgm": "Assets/audio/bgm_office.wav",
  "bgImage": "Assets/ui/office.txt",

  "require": [{
    "type": "fatigue",
    "op": "lt",
    "value": 80
  }],

  "effects": [
    {"type":"city_order","value":5},
    {"type":"tendency","key":"justice","value":1},
    {"type":"reveal_character","key":"kang_taewon"}
  ],

  "text": [
    "story.case_1042.0",
    "story.case_1042.1"
  ],

  "choices": [{
    "text":"story.case_1042.choice.0",
    "next":"case_1042_a",
    "require":[{
      "type":"tendency",
      "key":"justice",
      "op":"gte",
      "value":3
    }]
  }]
}
이펙트 타입
type설명
fatigue피로도 증감
monitoring감시 등급 증감
wealth재화 증감
city_order도시 질서
citizen_trust시민 신뢰
corruption오염도
tendency성향 수치
flag_add / flag_remove플래그 추가/제거
give_item / remove_item아이템 지급/제거
day / time / set_time날짜·시간
case_record처리 문서 기록
unlock_achievement업적 해제 NEW
reveal_character인물 등록 NEW
조건 타입 & 연산자
typeopkey

monitoringO—

tendencyOO

flagXO
